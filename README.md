# Boxing Shop Inventory System

Sistem i menaxhimit te inventarit per dyqan boksi - 100% Python me Flask.

## Struktura

```
api/
  index.py           - Aplikacioni Flask
  templates/
    base.html        - Template baze
    index.html       - Faqja kryesore
    product_form.html - Forma per produkte
requirements.txt     - Dependencies
vercel.json          - Konfigurimi Vercel
```

## Funksionalitetet

- Shfaq produktet me statistika
- Kerko dhe filtro sipas kategorise
- Shto/Ndrysho/Fshi produkte
- Shto/Hiq stok me nje klik
- Database SQLite
